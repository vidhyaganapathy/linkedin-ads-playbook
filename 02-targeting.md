# 02 · Targeting

## Start with the ICP, not the targeting menu

Write the ICP down before opening Campaign Manager:

| Field | Example |
|---|---|
| Company size | [e.g. 11–200 employees] |
| Industry | [e.g. software, fintech] |
| Location | [e.g. Australia] |
| Roles | [e.g. founder, CEO, CTO, Head of Product] |
| Seniority | [e.g. Director and above] |
| Trigger | [e.g. raised funding, hiring engineers] |

## Targeting options, best to broadest

| Option | When I use it |
|---|---|
| **Matched audiences: company list** | Known target accounts (ABM). Upload a list of companies. |
| **Matched audiences: contact list** | Known people, e.g. built from Apollo or Firmable. Respect privacy and consent rules. |
| **Retargeting** | Website visitors, video viewers, document openers, lead form openers, page engagers |
| **Job function + seniority** | Broader reach when role titles vary a lot |
| **Job titles** | Precise, but keep the list tight and review it |
| **Skills / interests** | Supporting layer only; noisy on its own |

## Rules

- **Exclude what wastes spend:** current customers, employees, competitors, students and job seekers if they're not the buyer.
- **Don't over-layer.** Each extra AND condition shrinks the audience and raises costs.
- **Separate campaigns by audience temperature:** cold, warm (engagers), hot (high intent).
- **Check the audience size forecast** before launch; too small won't deliver, too broad wastes spend.

## Audience naming

```
[Temp]_[Source]_[Description]
e.g. Cold_CompanyList_AU-SaaS-11-200 / Warm_Video50_Q4 / Hot_DocOpeners_30d
```
